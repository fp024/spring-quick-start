## 서평
* AOP 관련 예제가 점진적으로 이해하기 쉽게 되어있음.
* JDBC 진행방식도 자세히 되어있음.
* 레거시 코드를 근래의 프레임워크로 전환할 일을 맡게 될 수도 있는데, 
책에서 Model 1, Model 2 아키텍처 기반으로 개발 흐름을 보여줘서 레거시 코드의 신규 프레임워크 전환시 전반적인 이해에 도움이 많이 될 것으로 보입니다.
